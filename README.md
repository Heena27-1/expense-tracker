# 💰 Expense Tracker

A responsive personal expense tracker built with React and Vite to manage income and expenses efficiently.

## 🚀 Features

* Add income and expense transactions
* Edit existing transactions
* Delete transactions
* Automatic balance calculation
* Income and expense summaries
* Search transactions
* Filter by transaction type
* Filter by category
* Expense breakdown using an interactive pie chart
* Persistent data storage using Browser LocalStorage
* Responsive design for desktop and mobile devices

## 🛠️ Tech Stack

* React.js
* Vite
* JavaScript
* CSS
* Recharts
* LocalStorage

## 📊 Dashboard

The application provides a simple dashboard to view:

* Total Balance
* Total Income
* Total Expenses
* Expense distribution by category
* Recent transactions

## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/Heena27-1/expense-tracker.git
```

Navigate to the project:

```bash
cd expense-tracker
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.
